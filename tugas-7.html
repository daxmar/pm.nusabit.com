(Buat HTML dari NOL pakai Notepad ++! Langkah demi langkah + checklist!)

6 Langkah Buat HTML

  1. 1

    Install Notepad++

    1. Buka browser → googling "download notepad++"
    2. Download dari notepad-plus-plus.org
    3. Install (Next → Next → Finish)
    4. Buka: Win+R → notepad++

  2. 2

    Tulis Struktur HTML

    Copy-paste kode ini ke Notepad:

    <!Doctype html>
    <html lang="id">
    <head>
    <title>Portofolio Saya</title>
    </head>
    <body>
    <h1>Halo, saya [NAMA]</h1>
    <p>Selamat datang di portofolio HTML pertama saya!</p>
    <p>Saya sedang belajar membuat halaman web menggunakan Notepad++.</p>
    </body>
    </html>
  3. 3

    Save as .html

    Ctrl+S → Nama: portfolio.html → Save as type: All Files → Save

  4. 4

    Buka di Browser

    Double-click file portfolio.html → otomatis buka Chrome/Edge!

  5. 5

    Tambah Semantic

    Edit di Notepad, tambah elemen dari cheatset playground. Save → Refresh browser (F5)
