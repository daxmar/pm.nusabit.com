Konsep Dasar

Apa itu HTML?

HTML (HyperText Markup Language) bukan bahasa pemrograman, melainkan bahasa markah (markup) yang memberitahu browser bagaimana menyusun konten.

Analogi "The Big Three"

HTML = Tulang/Kerangka Menentukan struktur (kepala, badan, kaki).
CSS = Kulit/Baju Menentukan tampilan (warna, gaya, posisi).
JS = Otak/Otot Menentukan fungsi & interaksi (gerak, logika).

Asal Mula

Diciptakan oleh Sir Tim Berners-Lee pada tahun 1991 di CERN. Awalnya, HTML hanya memiliki 18 tag sederhana untuk berbagi dokumen ilmiah antar peneliti.

"Saya hanya mengambil ide hypertext dan menghubungkannya dengan TCP dan DNS dan — ta-da! — World Wide Web."

Evolusi HTML5

  • 1999
    HTML 4.01 Standar lama yang bertahan lama. Masih kaku dan butuh plugin (Flash) untuk video.
  • 2014
    HTML5 (Era Modern) Revolusi web! Mendukung Video, Audio, Animasi, dan Aplikasi Web canggih secara native.

Anatomi Halaman Web

Setiap file HTML wajib memiliki struktur ini agar terbaca oleh browser.

<!DOCTYPE html>
<html lang="id"> <!-- BAGIAN KEPALA (Info) -->

<head>
<meta charset="UTF-8">
<title>Judul di Tab Browser</title>
</head>

<!-- BAGIAN TUBUH (Konten) -->
<body>
<h1>Halo Dunia!</h1>
<p>Selamat datang di web saya.</p>
</body>

</html>

<!DOCTYPE html>

Deklarasi wajib di baris pertama. Memberitahu browser bahwa ini adalah dokumen HTML5 modern.

<html> ... </html>

Elemen akar (root) yang membungkus seluruh kode HTML.

<head> ... </head>

Berisi metadata, judul tab, dan link ke CSS. Konten di sini TIDAK tampil di halaman utama.

<body> ... </body>

Wadah untuk semua konten yang TAMPIL di layar (teks, gambar, video, tombol).

Tag HTML Paling Sering Dipakai

Teks & Judul

  • <h1> s/d <h6>
    Untuk judul (Heading). h1 paling besar.
  • <p>
    Untuk paragraf teks biasa.
  • <br> & <hr>
    Ganti baris & Garis horizontal.

Media & Link

  • <a href="...">
    Anchor/Link untuk pindah halaman.
  • <img src="...">
    Menampilkan gambar. Wajib ada atribut src.
  • <ul> & <li>
    Membuat daftar poin (List).

Wadah (Container)

  • <div>
    Pembungkus blok umum (paling sering dipakai).
  • <span>
    Pembungkus teks dalam baris (inline).
  • <form>
    Wadah untuk input data pengguna.

Kekuatan Atribut

Tag HTML bisa memiliki informasi tambahan yang disebut Atribut. Atribut selalu ditulis di dalam tag pembuka. Formatnya: nama="nilai".

Atribut Digunakan di Tag Fungsi
href <a> Menentukan tujuan link (URL website atau file).
src <img>, <video> Source. Menentukan lokasi file gambar/video yang akan ditampilkan.
alt <img> Teks alternatif jika gambar gagal dimuat (penting untuk SEO).
class Semua Tag Memberi nama kelompok untuk dihias dengan CSS.
id Semua Tag Memberi nama unik (identitas) pada satu elemen spesifik.

Semantic HTML

Menulis HTML bukan cuma soal "tampil benar", tapi juga "bermakna benar". Gunakan tag yang sesuai dengan fungsinya agar kode rapi dan mudah dibaca mesin pencari (Google).

  • Gunakan <header> Untuk bagian atas web (logo, menu). Jangan pakai div biasa.
  • Gunakan <main> Untuk pembungkus konten utama halaman.
  • Gunakan <footer> Untuk bagian kaki web (copyright, kontak).
<header>
<nav>
<main>
<footer>
