Konsep Dasar

Apa itu ?

Bayangkan kamu mendaftar ekskul di sekolah — pasti ada formulir kertas untuk diisi, kan? Nah, di website, Form adalah "kertas digital" yang memungkinkan user mengirimkan data ke web!

Analogi: Form = Kotak Surat Ajaib 🗳️. User tulis pesan, klik kirim, web terima!


<form>
<input type="text" placeholder="Nama kamu">
<button>Kirimbutton>
form>

Jenis-Jenis Input

Banyak tipe input yang bisa dipakai! Setiap tipe punya fungsi unik.

Teks biasa. Paling sering dipakai untuk nama, alamat, pesan.

<input type="text" placeholder="Nama lengkap">

Teks rahasia (jadi bintang ***). Cocok untuk kata sandi!

<input type="password" placeholder="Kata sandi">

Input khusus angka. Ada tombol + / - otomatis!

<input type="number" placeholder="Umur" min="1">

Validasi format email otomatis (harus ada @).

<input type="email" placeholder="email@contoh.com">

Kalender interaktif untuk milih tanggal lahir.

<input type="date">

Pemilih warna dengan visual color picker!

<input type="color" value="#ff0000">

Atribut Super Penting

Tiga sahabat karib form: Label, Placeholder, Required!

Teks petunjuk di luar kotak input. Memberi tahu user "Apa yang harus diisi di sini?"

<label>Nama Lengkap:label>
<input type="text">

placeholder="..."

Teks petunjuk di dalam kotak input. Hilang saat user mulai mengetik.

<input placeholder="Contoh: Budi Santoso">

required

Wajib diisi! Kalau kosong, form gagal dikirim. User akan diperingatkan otomatis.

<input type="text" required>

Pro Tips

  • Selalu gunakan — membantu screen reader
  • required mencegah form kosong dikirim
  • placeholder memberi contoh isian
  • Gunakan type="number" untuk angka saja
