Aktivitas Siswa: Belajar & Bermain Koding Pilih tantangan dan mulai coding!

Tantangan 1: Halaman Sederhana

Buat halaman web dengan heading, paragraf, dan tombol. Tambahkan gambar atau link untuk membuatnya lebih menarik!

Tingkat: Pemula

Tantangan 2: Daftar & Formulir

Buat daftar belanja dengan ordered/unordered list, dan tambahkan formulir untuk menambah item baru.

Tingkat: Menengah

Tantangan 3: Galeri Media

Buat galeri dengan gambar, video, dan audio. Gunakan elemen media untuk menampilkan konten multimedia.

Tingkat: Lanjutan

Tantangan 4: Layout Kreatif

Desain layout halaman dengan header, main content, dan footer. Gunakan div dan semantic elements untuk struktur.

Tingkat: Kreatif

Tantangan 5: Quiz HTML

Buat quiz sederhana dengan pertanyaan tentang HTML. Gunakan form dan input untuk interaksi.

Tingkat: Interaktif

Tantangan 6: Kreatif Bebas

Buat apa saja yang kamu inginkan! Halaman pribadi, blog mini, atau game sederhana. Gunakan imajinasimu!

Tingkat: Expert

Tantangan 7: Kartu Nama

Buat kartu nama digital dengan foto bulat, teks berwarna, dan link sosmed menggunakan atribut style.

Tingkat: Styling

Tantangan 8: Interaksi Tombol

Buat tombol yang bisa bereaksi! Gunakan atribut onclick untuk pesan alert dan CSS hover untuk efek visual.

Tingkat: Interaksi

Tantangan 9: Form Pendaftaran

Buat formulir pendaftaran akun game! Gunakan berbagai tipe input seperti text, password, date, dan color.

Tingkat: Formulir

Klik salah satu tantangan di atas untuk memuat kode starter ke editor. Edit dan lihat hasilnya di preview!

Cheat Sheet HTML Dasar

Struktur Dasar

Deklarasi Versi HTML:

<!DOCTYPE html>

Pembungkus Utama:

<html lang="id">...</html>

Metadata (Info Halaman):

<head>...</head>

Judul Tab Browser:

<title>Judul Halaman</title>

Teks & Heading

Judul (h1 s/d h6):

<h1>Judul Besar</h1>

Paragraf:

<p>Teks paragraf...</p>

Teks Tebal & Ganti Baris:

<strong>Tebal</strong> <br>

Link / Tautan:

<a href="url">Klik Saya</a>

Media

Gambar (src=lokasi):

<img src="foto.jpg" alt="Ket">

Video Player:

<video src="v.mp4" controls></video>

Audio Player:

<audio src="s.mp3" controls></audio>

Embed (YouTube/Peta):

<iframe src="URL"></iframe>

Daftar

Daftar Angka (Ordered):

<ol><li>Satu</li><li>Dua</li></ol>

Daftar Poin (Unordered):

<ul><li>A</li><li>B</li></ul>

Formulir

Wadah Formulir:

<form action="#">...</form>

Input & Tombol:

<input type="text"> <button>OK</button>

Area Teks Panjang:

<textarea>Isi...</textarea>

Semantic & Layout

Wadah Blok (Layout):

<div class="box">...</div>

Wadah Teks (Inline):

<span class="txt">...</span>

Bagian Atas & Bawah:

<header>...</header> <footer>...</footer>

Styling (CSS)

Warna Teks:

style="color: red;"

Warna Latar:

style="background-color: blue;"

Posisi Teks:

style="text-align: center;"

Sudut Melengkung:

style="border-radius: 50%;"
