Logika Dasar
Pemrograman

Komputer hanya mengerti YA atau TIDAK — ibarat lampu yang cuma bisa ON atau OFF. Yuk, belajar cara "berpikir seperti komputer" dengan logika! 💡

Konsep Dasar

Apa itu Logika Pemrograman?

Logika pemrograman adalah cara berpikir terstruktur yang dipakai untuk menyusun langkah-langkah penyelesaian masalah — seperti resep masakan yang harus diikuti urutannya!

Analogi: "Bangun tidur → Gosok gigi → Mandi → Sarapan" adalah algoritma! Kalau langkahnya terbalik, hasilnya kacau! 🫠

// Contoh Logika Sederhana

if (hujan == true) {
  bawaPayung();
} else {
  jalanSantai();
}

// Pseudocode: bahasa manusia
// yang mirip kode!

3 Pilar Logika Pemrograman

Setiap program komputer dibangun dari 3 struktur dasar ini!

1. Sequence 🔢

Urutan langkah berurutan

Setiap instruksi dijalankan satu per satu dari atas ke bawah. Gak boleh loncat atau terbalik!

1. Nyalakan komputer
2. Buka browser
3. Ketik alamat website
4. Enter

2. Selection 🔀

Pilih salah satu kondisi

Komputer bisa memilih tindakan berdasarkan kondisi tertentu. IF - ELSE!

if (nilai >= 75) {
  lulus = true;
} else {
  lulus = false;
}

3. Iteration 🔄

Ulang langkah berkali-kali

Komputer jago banget ngulang tugas ribuan kali tanpa capek. Looping / Perulangan!

for (i = 1; i <= 5; i++) {
  cuciPiring();
  keringkan();
}
// Ulang 5 kali!

Operator Logika

"Kata sambung" yang menghubungkan kondisi-kondisi dalam logika!

AND (&&)

Semua kondisi harus BENAR supaya hasilnya benar.

// Dua-duanya harus benar!
if (hujan == false &&
    bawaUang == true) {
  beliEsKrim();
}

✅ ✅ = ✅ | ✅ ❌ = ❌ | ❌ ❌ = ❌

OR (||)

Cukup SATU kondisi benar, hasilnya benar.

// Salah satu benar cukup!
if (punyaPensil == true ||
    punyaPulpen == true) {
  bisaNulis();
}

✅ ✅ = ✅ | ✅ ❌ = ✅ | ❌ ❌ = ❌

NOT (!)

Membalikkan kondisi. Benar jadi salah, salah jadi benar.

// Kebalikan!
if (!sedangHujan) {
  jalanJalan();
}
// Artinya: "JIKA TIDAK hujan"

!✅ = ❌ | !❌ = ✅

Flowchart: Peta Logika

Sebelum nulis kode, buat dulu diagram alir — biar gak bingung!

Simbol Flowchart

  • ⬤ Mulai/Selesai — Terminal
  • ▱ Proses — Aksi / langkah
  • ◇ Decision — Pilihan YA/TIDAK
  • → Arrow — Alur / arah langkah

📝 Latihan: Buat Flowchart

"Cek apakah bisa main game: PR selesai AND sudah jam 7 malam"

1. 🟢 Mulai
2. ▱ Cek PR selesai?
3. ◇ PR selesai? → ❌ → "Belum boleh main"
4. ◇ PR selesai? → ✅ → Cek jam ≥ 19:00?
5. ◇ Jam ≥ 19:00? → ❌ → "Tunggu sampai jam 7"
6. ◇ Jam ≥ 19:00? → ✅ → "Silakan main! 🎮"
7. 🟢 Selesai
