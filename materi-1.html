Di sini kita akan "memasak" kode bareng-bareng! Hari ini kita mulai dengan Algoritma — yaitu langkah-langkah logis untuk menyelesaikan masalah. Seperti resep masakan, algoritma harus urut, jelas, dan tepat!

Resep Algoritma Sederhana: "Rebus mie instan: 1) Rebus air, 2) Masukkan mie, 3) Tunggu 3 menit, 4) Tiriskan, 5) Beri bumbu, 6) Sajikan! 🍜"

// Algoritma dalam kode

let airMendidih = false;

// 1. Mulai
rebusAir();
airMendidih = true;

// 2. Proses
masukkanMie();
tunggu(3);
tiriskan();

// 3. Selesai
sajikan();

Code Path Finder 🎮

Game ini dirancang untuk membantu kamu memahami algoritma dan logika pemrograman dengan cara yang menyenangkan!

Tugasmu: gerakkan robot 🤖 dari titik Start ke Bendera 🏁 sambil menghindari bom 💣! Susun perintah seperti programmer sungguhan!

Mainkan Sekarang! Kerjakan Tugas

🎮 Preview Game (Grid 5x5)

🤖 Robot (biru) → 🏁 Bendera (merah). Hindari 💣 bom!

📖 Cara Bermain

Gampang kok! Ikuti langkah-langkah ini:

👀

1. Amati Peta

Lihat posisi robot 🤖, bendera 🏁, dan bom 💣. Cari jalur aman!

✍️

2. Susun Perintah

Klik tombol Atas ⬆️, Bawah ⬇️, Kiri ⬅️, Kanan ➡️ untuk memberi instruksi ke robot!

🚀

3. Jalankan!

Klik "JALANKAN" dan lihat robot bergerak sesuai perintahmu!

Tips Sukses

  • Rencanakan langkah sebelum menjalankan robot
  • Perhatikan posisi bom dan cari jalur terpendek
  • Gunakan "Acak Ulang" jika peta terlalu sulit
  • Jangan takut gagal — belajar dari kesalahan!

Konsep Pemrograman

Tanpa sadar, kamu sudah belajar konsep penting ini lewat game!

Sequence

Perintah yang kamu susun berurutan (Atas Kanan Bawah) adalah contoh Sequence!

Path Finding

Mencari jalur terpendek dan aman dari Start ke Finish — ini Path Finding!

Problem Solving

Menganalisis peta, merencanakan strategi, lalu mengeksekusi — itulah Problem Solving!
