Input Magic

Tag input

Input seperti "telinga super web" yang bisa mendengar setiap huruf yang diketik user secara real-time! Proses lengkap: 1) User ketik di kotak input, 2) Saat tombol diklik atau Enter ditekan, JS "mendengar" isi kotak dengan perintah ajaib document.getElementById('namaInput').value, 3) Web proses data itu (misal tambah "Halo "), 4) Tampil respon personal. Contoh nyata: Facebook login baca emailmu, Google search baca kata kunci.
Gampang banget: document.getElementById('namaInput').value → ambil teks → jadi milik JS! Magic! ✨
Langkah detail: id unik → getElementById → .value ambil isi → pakai di alert/string. Praktek sekarang di demo!


<input id="namaInput" placeholder="Nama kamu?" />
<button onclick="haloNama()">Halo!button>


function haloNama() {
  let nama = document.getElementById('namaInput').value;
  alert('Halo '+nama+'! 👋');
}

Input Number

Web jadi kalkulator pintar! Bisa hitung umur dari tahun lahir, skor game, uang jajan tersisa, diskon belanja. Keistimewaan type="number": user hanya bisa input angka (ga bisa huruf A-Z), otomatis ada tombol +-, validasi min/max. Proses: user ketik tahun (misal 2015) → JS ambil dengan .value → parseInt() ubah teks ke angka → hitung 2026 - lahir → tampil umur. Berguna untuk app: toko online hitung total, game hitung level/score, form umur/orangtua. Input angka → tombol hitung → hasil instan + akurat! 🧮✨


<input type="number" id="umurLahir" placeholder="Tahun lahir">
<button onclick="hitungUmur()">Hitung Umur!button>

function hitungUmur() {
  let lahir = document.getElementById('umurLahir').value;
  let umur = 2026 - lahir;
  alert('Umurmu: '+umur+' tahun! 🎂');
}

Game Tebak Angka Pintar

Aktivitas ultimate: gabung SEMUA skill → input + onclick + if-else + variable global + Math.random()! Web generate angka rahasia 1-100 sekali di awal. Tiap tebakan: ambil input → +1 counter → bandingkan: == menang, < kasih petunjuk BESAR, > KECIL. Tampil di div, update counter real-time. State: let rahasia & percobaan di luar function (global). Reset setelah menang. Fun seperti Mastermind game! Buat adik ketagihan main sambil belajar logika. Praktek: ubah range 1-50, tambah high score, animasi win. Level pro: multiplayer tebak bergantian! 🎲🏆 Super fun & challenging buat SMP! 🎮

Tebak Angka 1-100!

Masukkan angka → klik → dapat petunjuk! 🎯
Percobaan: 0
let angkaRahasia = Math.floor(Math.random()*100) + 1;
let percobaan = 0;

function tebakAngka() {
  let tebakan = document.getElementById('tebakInput').value;
  percobaan++;
  if(tebakan == angkaRahasia) {
    alert('🎉 BENAR! '+percobaan+' percobaan!');
  } else if(tebakan < angkaRahasia) {
    alert('📈 Terlalu KECIL! Coba lebih besar');
  } else {
    alert('📉 Terlalu BESAR! Coba lebih kecil');
  }
}
