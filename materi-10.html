Pilihan Ganda
Radio, Checkbox & Dropdown

Gak semua data harus diketik manual! Dengan Radio Button, Checkbox, dan Dropdown, user cukup klik-klik aja — cepat, rapi, anti-salah ketik! 🚀

Kenapa?

Kenapa Harus Ada Pilihan?

Bayangkan kalau kamu harus mengetik "Laki-laki" atau "Perempuan" setiap kali daftar — pasti capek dan rawan salah ketik! Website pakai Pilihan biar lebih cepat, mudah, dan akurat.

Prinsip: "Kalau bisa dipilih, jangan diketik!" — lebih user-friendly!


<input type="text" placeholder="Ketik 'Laki' atau 'Perempuan'">


<input type="radio" name="gender" value="L"> Laki
<input type="radio" name="gender" value="P"> Perempuan

Jauh lebih simpel! ✅

Tiga Pahlawan Pilihan

Kenali 3 jenis input pilihan yang wajib kamu kuasai!

Radio Button 🔘

type="radio"

Hanya boleh pilih SATU opsi. Seperti memilih jenis kelamin atau jawaban ujian.

<input type="radio" name="kelas"> 7A
<input type="radio" name="kelas"> 7B

🔑 name sama = satu grup!

Checkbox ☑️

type="checkbox"

Boleh pilih BANYAK opsi sekaligus. Seperti milih hobi atau topping pizza!

<input type="checkbox"> Coding
<input type="checkbox"> Gaming
<input type="checkbox"> Membaca

💡 Bisa centang semua atau tidak sama sekali!

Dropdown 📋

👦 Laki-laki

Klik pilihan di samping, lalu tekan tombol! 👆

Web akan merangkum semua pilihanmu!

Aturan Penting!

Ini dia rahasia yang harus kamu ingat!

Radio = Satu Grup

Agar radio button saling "tahu" dan cuma bisa milih satu, beri name yang SAMA!

Checkbox = Bebas!

Gak perlu name sama. User bisa centang SEMUA atau tidak sama sekali. Bebas!

Dropdown = Value

Atribut value pada adalah data yang dikirim ke server. Teks di dalam tag hanya tampilan!

Ini form lengkap yang bisa langsung kamu pakai di playground!

Pro Tips

  • Radio pakai name SAMA = satu grup
  • Checkbox bisa pakai name[] (array) untuk PHP
  • Dropdown gunakan value untuk data ke server
  • Bisa kombinasikan dengan onclick untuk interaksi!

🔑 Kode Ajaib:

document.querySelector('input[name="kelas"]:checked').value

Ambil nilai radio/checkbox yang sedang terpilih!
