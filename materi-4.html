Atribut style="..."

Ingat analogi "Baju"? Kita bisa memakaikan baju langsung ke elemen HTML menggunakan atribut style. Ini adalah cara tercepat untuk mengubah tampilan.

Rumusnya: Properti: Nilai; (Jangan lupa titik dua dan titik koma!)

<!-- Mengubah Warna Teks -->
<h1 style="color: red;">Judul Merah</h1>

<!-- Mengubah Background -->
<div style="background-color: blue; color: white;">
Kotak Biru Teks Putih
</div>

<!-- Mengubah Ukuran Font -->
<p style="font-size: 20px;">Tulisan Besar</p>

Warna (Color)

color: red;

Bisa pakai nama (red, blue) atau kode hex (#ff0000).

Latar (Background)

background-color: black;

Memberi warna latar belakang elemen.

Aa

Ukuran (Font Size)

font-size: 24px;

Mengatur besar kecilnya huruf dalam pixel (px).

Jurus Styling Tambahan

Posisi Teks

Biar judul ada di tengah, gunakan text-align.

<h1 style="text-align: center;">
Judul di Tengah
</h1>

Sudut Tumpul

Biar kotak tidak tajam, gunakan border-radius.

<img src="foto.jpg" style="border-radius: 50%;">

Tips: Nilai 50% membuat gambar jadi bulat sempurna!

Ganti Gaya Huruf

Gunakan font-family untuk mengubah jenis tulisan.

style="font-family: monospace;"

Profil Keren

<h3 style="text-align: center;">

Contoh hasil penggunaan text-align: center dan border-radius: 50% pada gambar profil.

Teori Warna

Kode Rahasia Warna

Komputer tidak hanya tahu warna "Red" atau "Blue". Komputer bisa menampilkan 16 juta warna menggunakan Kode Hex.

Kode Hex dimulai dengan tanda pagar # diikuti 6 karakter (angka 0-9 dan huruf A-F).

#FF0000Merah
#00FF00Hijau
#0000FFBiru
#FFFF00Kuning

Campuran Warna (RGB)

Semua warna di layar HP/Laptopmu terbuat dari campuran cahaya Red, Green, dan Blue!

Portal Antar Halaman

Web tanpa link itu seperti rumah tanpa pintu. Gunakan tag <a> (Anchor) untuk membuat "portal" ke halaman lain atau website lain.

Link ke Website Lain (External)

<a href="https://google.com" target="_blank">Ke Google</a>

Tips: target="_blank" membuat link terbuka di tab baru.

Link ke File Sendiri (Internal)

<a href="biodata.html">Lihat Biodata</a>

Pastikan nama file sama persis (huruf besar/kecil berpengaruh!).

(Ini contoh tombol link!)

Jendela Dunia (Iframe)

Bagaimana cara menampilkan video YouTube atau Peta Google di web kita? Jawabannya adalah Iframe.

Iframe seperti melubangi web kita untuk mengintip web orang lain.

<!-- Embed Video Youtube -->
<iframe
width="560"
height="315"
src="https://www.youtube.com/embed/twbBo1ybJwE">
</iframe>

Tips: Di YouTube, klik tombol "Share" -> "Embed" untuk mendapatkan kode iframe otomatis!
