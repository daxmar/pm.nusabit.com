 # Silabus Pembelajaran Pemrograman Web Dasar

## Identitas Pembelajaran

- **Mata pelajaran:** Pemrograman Web Dasar
- **Sasaran:** Pemula / siswa SMP dan sederajat
- **Durasi:** 10 pertemuan
- **Fokus teknologi:** HTML5, CSS dasar, JavaScript dasar, dan pengenalan PHP
- **Model pembelajaran:** Penjelasan singkat, demonstrasi, praktik langsung, permainan edukatif, dan proyek kecil
- **Perangkat:** Browser, editor teks atau Notepad++, dan playground HTML interaktif

## Tujuan Umum

Setelah menyelesaikan pembelajaran, peserta didik diharapkan mampu:

1. Menjelaskan algoritma, logika, dan langkah penyelesaian masalah.
2. Membuat halaman web menggunakan struktur HTML yang benar.
3. Mengatur tampilan halaman menggunakan CSS dasar.
4. Membuat halaman web yang interaktif dengan JavaScript.
5. Menggunakan input, form, pilihan, validasi, dan tombol submit.
6. Menyusun halaman yang rapi, semantik, responsif, dan lebih mudah diakses.
7. Membuat proyek web sederhana yang menggabungkan HTML, CSS, dan JavaScript.

## Susunan Silabus

| Pertemuan | Materi Pokok | Tujuan Pembelajaran | Praktik / Produk |
|---|---|---|---|
| 1 | **Pengenalan algoritma dan logika pemrograman** | Peserta didik memahami algoritma, pseudocode, sequence, selection, iteration, dan problem solving. | Bermain *Code Path Finder* dan menulis algoritma kegiatan sehari-hari. |
| 2 | **Logika dasar pemrograman** | Peserta didik memahami kondisi benar/salah, operator perbandingan, operator logika, `if-else`, dan perulangan. | Membuat solusi dari beberapa teka-teki logika dan permainan detektif sederhana. |
| 3 | **Pengenalan dan struktur HTML5** | Peserta didik mengenali fungsi HTML serta penggunaan `doctype`, `html`, `head`, `title`, `body`, heading, paragraf, link, dan gambar. | Membuat halaman sederhana bertema profil diri atau halaman informasi. |
| 4 | **CSS dasar dan hyperlink** | Peserta didik mampu mengubah warna, ukuran teks, latar belakang, posisi teks, sudut elemen, dan membuat link antarhalaman. | Menghias halaman profil dan membuat navigasi sederhana. |
| 5 | **JavaScript dan event `onclick`** | Peserta didik memahami fungsi JavaScript pada halaman web, event `onclick`, `alert`, variabel, dan perubahan tampilan elemen. | Membuat tombol ajaib, penghitung klik, serta tombol yang mengubah warna atau teks. |
| 6 | **Input, tombol submit, dan validasi** | Peserta didik mengambil data dari `input` dengan `.value`, mengolah angka, merespons form, dan melakukan validasi sederhana. | Membuat sapaan berdasarkan nama, kalkulator umur, form validasi, dan game tebak angka. |
| 7 | **Sejarah web dan semantic HTML** | Peserta didik memahami perkembangan HTML, CSS, JavaScript, dan PHP serta menggunakan `header`, `nav`, `main`, `section`, `article`, `aside`, dan `footer`. | Mengubah halaman berbasis `div` menjadi halaman dengan struktur semantik. |
| 8 | **Layout praktis, tabel, dan aksesibilitas** | Peserta didik membuat layout yang mudah dibaca, menyajikan data dengan `table`, `thead`, `tbody`, `th`, `td`, dan menambahkan atribut aksesibilitas pada tombol. | Membuat tabel jadwal atau papan skor yang rapi dan ramah pengguna. |
| 9 | **Form dan berbagai jenis input** | Peserta didik menggunakan `text`, `password`, `number`, `email`, `date`, `color`, serta memahami `id`, `name`, dan data form. | Membuat form pendaftaran akun game dengan beberapa jenis input. |
| 10 | **Radio button, checkbox, dropdown, dan proyek akhir** | Peserta didik membedakan pilihan tunggal dan pilihan jamak, membaca pilihan pengguna, serta menggabungkan materi sebelumnya. | Membuat kuis pilihan ganda, form pilihan, atau mini game dengan skor dan saldo/koin. |

## Rincian Kompetensi

### 1. Pengetahuan

- Konsep algoritma, logika, sequence, selection, dan iteration.
- Fungsi HTML sebagai struktur halaman.
- Fungsi CSS sebagai pengatur tampilan.
- Fungsi JavaScript sebagai pengatur interaksi.
- Dasar form, validasi, semantic HTML, tabel, dan aksesibilitas.

### 2. Keterampilan

- Menulis dan menyimpan file `.html`.
- Membaca serta memperbaiki kesalahan struktur kode.
- Menghubungkan tombol dengan fungsi JavaScript.
- Mengambil dan menampilkan data dari input.
- Membuat perubahan tampilan secara dinamis.
- Menguji halaman pada browser dan playground.

### 3. Sikap

- Teliti dalam menulis tag, atribut, dan tanda baca kode.
- Berani mencoba, menguji, dan memperbaiki kesalahan.
- Terbiasa memecah masalah menjadi langkah-langkah kecil.
- Mengutamakan kerapian, kemudahan penggunaan, dan aksesibilitas.

## Strategi Pembelajaran Setiap Pertemuan

1. **Pembukaan:** apersepsi, pertanyaan pemantik, dan pengenalan tujuan.
2. **Demonstrasi:** pengajar menunjukkan konsep melalui contoh yang dekat dengan kehidupan atau game.
3. **Praktik terbimbing:** peserta didik menirukan contoh dan memodifikasinya.
4. **Tantangan mandiri:** peserta didik menyelesaikan tugas atau tantangan di playground.
5. **Refleksi:** membahas hasil, kesalahan umum, dan ide pengembangan berikutnya.

## Proyek Akhir

Peserta didik membuat satu halaman web interaktif dengan tema bebas, misalnya:

- Dashboard saldo atau koin game.
- Kuis pilihan ganda dengan skor.
- Form pendaftaran karakter game.
- Papan skor atau jadwal kegiatan.
- Profil pribadi interaktif.

### Kriteria Minimal Proyek

- Memiliki struktur HTML yang lengkap dan semantik.
- Memiliki styling CSS yang konsisten dan mudah dibaca.
- Memiliki minimal dua interaksi JavaScript.
- Menggunakan minimal satu input atau pilihan pengguna.
- Menampilkan hasil interaksi secara langsung pada halaman.
- Dapat dibuka dan diuji di browser tanpa error utama.
