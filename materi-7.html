Mulai Sejarah

Sejarah Lengkap: HTML → PHP → HTML5

Perjalanan web dari dokumen statis ke aplikasi dinamis interaktif!

1991

HTML Lahir - Tim Berners-Lee (CERN)

18 tag sederhana untuk berbagi dokumen ilmiah. Hanya teks + link dasar. World Wide Web lahir!

1999

HTML 4.01 + CSS1/2

Standar stabil. CSS pisah styling dari HTML. Masih butuh Flash untuk video/game.

2004

PHP Server-Side Magic

Rasmus Lerdorf ciptakan PHP. Web jadi DINAMIS: database, login, form proses server-side. HTML + PHP = CMS (WordPress)!

2014

HTML5 Revolusi!

  • Video/Audio native (no Flash)
  • Canvas/SVG untuk game/grafik
  • Responsive design mobile-first
  • Semantic tags (header, main)

HTML5 + PHP + JS = Modern Web Apps!
